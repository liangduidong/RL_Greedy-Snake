## 核心:

### 1. **深度Q学习(DQN)算法**
- 使用神经网络来学习Q值函数
- 经验回放机制,从历史经验中学习
- 双网络结构(主网络+目标网络)提高稳定性

### 2. **智能状态表示(11维特征)**
- 前方/左/右是否有危险
- 当前移动方向(4个方向)
- 食物相对位置(上下左右)

### 3. **奖励系统**
- 吃到食物: +10分
- 死亡: -10分
- 防止无限循环:超过100*长度步数自动结束

### 4. **无监督自主学习**
- ε-greedy探索策略:初期多探索,后期多利用
- 自动重新开始新游戏
- 持续训练直到手动停止

### 5. **训练可视化**
- 实时显示当前回合、分数、最高纪录
- 显示平均分数,追踪学习进度

## 使用方法:

1. 安装依赖:
```bash
pip install pygame numpy torch
```

2. 运行程序,AI会自动开始训练

3. 按 **Q键** 退出训练并查看统计

## 训练过程:
- 最初AI会随机探索,经常撞墙
- 几十回合后开始学会避障
- 几百回合后能稳定吃到食物
- 持续训练会越来越优秀!

观察epsilon值的下降,表示AI从探索转向利用学到的策略。祝训练成功! 🐍🤖
